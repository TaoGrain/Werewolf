# `mvp-v1` 规则与状态转换

## 阵容与胜负

- 6 人：2 狼人、1 预言家、1 女巫、2 平民。
- 所有狼人死亡时好人胜利。
- 存活狼人人数大于或等于存活好人人数时狼人胜利。

## 夜间

- 预言家先选择一名存活玩家查验阵营，不能查验自己，只保存自己的历史查验结果。
- 两名存活狼人先按座位号进行一轮队内交流，每人发言一次并提出建议目标；交流只对当时存活的狼队成员可见。
- 狼人交流完成后进入独立的出刀阶段，必须由主持人再次推进才会提交最终刀票。
- 狼人分别秘密提交最终目标；最高票为刀口，平票时按“游戏固定种子 + 天数”从并列目标中确定。
- 只剩一名狼人时跳过交流阶段，直接进入狼人出刀。
- 允许狼人自刀。
- 女巫首夜可自救，只能救当晚刀口；同一夜不能同时用两瓶药。
- 夜间死亡玩家没有遗言。

## 白天

- 存活玩家按座位号依次发言。
- 投票先独立提交，再统一公开目标和公开理由；可以弃票，但不能投自己。
- 弃票不计入任何候选人的票数；若本轮所有存活玩家均弃票，则无人出局并直接进入下一夜。
- 首轮最高票平票时只在并列候选人中重投一次；再次平票则无人出局。
- 被放逐玩家有一轮遗言。

## 状态机

```text
LOBBY
→ ROLE_ASSIGNED
→ NIGHT_SEER
→ NIGHT_WOLF_DISCUSSION
→ NIGHT_WOLF
→ NIGHT_WITCH
→ NIGHT_RESOLUTION
→ DAY_ANNOUNCEMENT
→ DAY_DISCUSSION
→ DAY_VOTING
→ DAY_RESOLUTION
→ NIGHT_SEER ... / FINISHED
```

所有转换、死亡、药物消耗和胜负均由 `GameEngine` 决定。模型只能返回行动意图。每个命令包含唯一 `command_id`，重复请求返回稳定回执，不重复产生副作用。

## 信息可见性

- `PUBLIC`：所有观战者与存活 Agent 可见。
- `PLAYER_PRIVATE`：只对指定玩家可见。
- `WOLF_TEAM_PRIVATE`：只对存活狼人可见。
- `HOST_PRIVATE`：只在获授权的上帝/调试视角可见。
- `POST_GAME_PUBLIC`：游戏结束后公开。

安全观战是默认模式。平民视图没有身份表；狼人只得到狼队友和自己有权看到的狼队交流历史；预言家只得到自己的查验；女巫只得到药物状态和当夜刀口。完整游戏状态不会发送给 LLM。
